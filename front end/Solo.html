Bienvenue dans le mode SOLOLEVELING


Les Règles du jeu FindMyWord sont simples,
Mon programme choisit un mot secret de 5 lettres que vous devez deviner.
À chaque tour, vous devez proposer un mot.
Mon programme va alors analyser cette proposition et indiquer, pour chaque lettre :

  • si elle est correcte et bien placée ( Vert ),
  • si elle est présente dans le mot mais mal placée ( Jaune ),
  • si elle est absente du mot ( Rouge ).
