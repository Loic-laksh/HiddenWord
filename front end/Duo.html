Bienvenue dans le mode DUO



Les Règles du jeu FindMyWord en Duo sont simples,
Mon programme choisit un mot secret de 5 lettres que vous devez deviner.
On considère qu’une lettre apparaît au maximum une seule fois dans le mot.
En mode Duo, vous jouez chacun votre tour pour tenter de marquer le plus de points !
À chaque essai, le joueur actif doit proposer un mot.
Mon programme va alors analyser cette proposition et indiquer, pour chaque lettre :

  • si elle est correcte et bien placée ( Vert ),
  • si elle est présente dans le mot mais mal placée ( Jaune ),
  • si elle est absente du mot ( Rouge ).
Si t'as toujours pas capté,
Vous jouez à tour de rôle, et chaque mot secret contient exactement 5 lettres sans aucune lettre répétée.
